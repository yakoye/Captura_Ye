# 回看与选帧界面设计

## 使用目标

录制后回看，任意挑选多处离散帧或连续范围，将所选画面导出给 AI 分析，也可合成视频或 GIF。

## 原界面问题及处理

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| 用文字清单展示数百张帧 | 无法直接比较画面，选择结果不直观 | 全部帧进入横向缩略图时间轴；每张显示画面、序号、时间和勾选状态 |
| 当前查看和已选状态混淆 | 查看下一帧容易被理解为替换选择 | 预览位置与导出集合分开；“查看中”文字及橙色标记、勾选及蓝底同时区分 |
| 空格同时播放和选帧 | 焦点改变后行为难预测 | 空格仅播放，Ctrl+Enter 选帧；局部作用域避开输入控件 |
| 播放、范围和导出按钮挤在多行 | 主操作难找，预览被挤压 | 预览下方仅播放与定位；选择操作靠近统计，导出固定在右下 |
| 目录和帧率字段拥挤 | 小数显示不全，目录遮挡操作 | 独立设置面板，帧率框 88 DIP，目录可换行和更改 |

## 布局和样式

默认展开 1120×850，支持 900×720 工作区，以系统可用区域为上限；收起后回到 440×90 的紧凑录制窗口。载入媒体后自动折叠录制参数，将空间交给编辑；参数随时可再展开。底部时间轴默认高 154 DIP，可拖动分隔线调整；帧卡片贴合图片和时间，不向下拉伸留白。

右侧设置宽 248 DIP，主操作固定在底部，其他设置在高度不足时滚动；顶部文件入口、中间预览、底部时间轴形成阅读顺序。间距以 4/8/12/16 DIP 组织；正文 12—13 DIP，标题 16—18 DIP。预览背景深色；其余颜色沿用主题资源。

选中状态同时通过勾选与蓝底显示，当前位置同时通过橙色和“查看中”文本显示。缩略图带帧号与时间，避免只靠颜色区分。

## 选择契约

普通点击只选择一帧；复选框或 Ctrl 点击增减离散帧；Shift 从锚点选择范围，Ctrl+Shift 将范围加入集合。查看和播放不改集合。导出开始时取排序、去重后的独立快照，处理期间选择集合冻结，避免显示结果与输出不一致。

缩略图虚拟化，仅解码可见和邻近帧；串行后台加载随滚动更新目标，缓存最多 160 张缩略图。播放和查看原帧使用独立路径，不以缩略图替代原尺寸导出。

## 播放器图标与帧角标

播放栏从左到右：第一帧、前5秒、前1秒、上一帧、播放/暂停、下一帧、后1秒、后5秒、最后一帧。按秒移动与逐帧按钮始终执行各自步长；逐帧模式复选框只决定左右键的行为。播放/暂停共用一个位置，随状态切换图标，悬停显示中文提示。

图标来自 [Material Design Icons](https://github.com/Templarian/MaterialDesign-SVG)，没有手工绘制；来源和许可随分发包提供。缩略图左上仅显示帧号数字，右上为独立勾选框，下方为时间。橙色“查看中”位于图片底部，查看与导出选择保持独立。

快捷键、多选方法和导出解释集中到右上角问号弹层，点击显示、关闭按钮或点击外部收起。移除底部常驻的两行说明，以及切换模式时的重复提示；没有实际状态时底栏整体折叠。

## 最终便携包的可见验证

直接启动 `dist/v9.0.7/CapturaYe/captura.exe`，使用独立设置 `temp/gui-v904`、`--no-hotkey --no-persist --review`。未修改用户常用配置。

- 默认 1120×850：没有重复标题，左侧预览上方不再占用一整行文件名/按钮栏；打开文件、实时画面、问号和文件名位于右侧面板，文件名在“导出选中帧”上方。
- 九个播放器按钮依次为首帧、前5秒、前1秒、前1帧、播放/暂停、后1帧、后1秒、后5秒、尾帧。前后逐帧按钮可见文字均为“1帧”，无障碍名称与悬停提示仍分别为“上一帧”“下一帧”。
- 帧号及当前时间 / 总时间紧跟“最后一帧”，与按钮同一行，最右端是“逐帧”开关；没有“当前查看”前缀。导出主按钮文字为“导出”。
- 实际拖动窗口到 900×720，截图元数据确认尺寸；按钮、帧号、时间、逐帧开关及固定导出主按钮均完整可见，右栏设置可滚动。
- 400 帧、25 秒媒体初始为 `1 / 400 帧 · 00:00:00.000 / 00:00:25.000`；点击尾帧后为 `400 / 400 帧 · 00:00:24.938 / 00:00:25.000`。在 900×720 下完整显示，无遮挡。
- 帧卡片左上数字、右上勾选、下方时间和橙色查看状态可见，缩略图按可见范围加载；默认底栏没有常驻操作说明。

## 验证边界

原生自动化不能组合按住修饰键和鼠标点击，因此 Ctrl/Shift 鼠标选择及 Shift 点勾选框由选择模型测试和事件接线检查验证，未做真实组合鼠标验收。未穷尽 DPI、系统主题、屏幕和编解码器；中文安装语言通过静默路径实测。窗口被覆盖或用户输入保护拦截时，刷新后再核对，不把被拦截的输入计作通过。

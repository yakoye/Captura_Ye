# v9.0.12 验证记录

日期：2026-10-23。本版按最新要求将查看与勾选导出分为独立状态，并增加预览缩放和平移、主窗口最大化／还原。

## 状态与缩放

`FrameSelection.Current` 只由查看更新，勾选、范围、全选及清空不再改动它。普通卡片点击只定位；勾选框沿用原生 Click，避免父容器和勾选框各处理一次导致重复切换。Ctrl/Shift 卡片操作、Shift 范围及 Ctrl+Enter 属于显式勾选。播放、普通方向键、进度条均不改导出集合，也不再因多选跳回第一帧。

视频与静态帧共用预览内容区，缩放相对适应窗口为 0.25—8 倍；按钮使用中心锚点，Ctrl＋滚轮使用指针锚点，包含居中留白和已滚动坐标的计算。放大后可左键拖动或拖动滚动条。打开新文件恢复适应，切换帧保留倍率；源媒体及导出像素不变。适应状态禁用滚动条，避免两条 Auto 滚动条互相挤占空间后残留。

主窗口仍可拖动边缘调整大小，新增最大化／还原按钮与计时区域双击；折叠录制条时隐藏该入口。新图标来自原有固定提交的 Material Design Icons 官方 SVG，来源与许可随包提供。

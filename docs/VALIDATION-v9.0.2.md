## 问题和边界

首次批量回归发现新版 FFmpeg 移除 `-vsync`，已根据功能支持选择 `-fps_mode` 或旧参数；130 项表达式触及 FFmpeg 解析限制，已修复产品为每批最多 64 项，并合并连续范围。原始失败日志保留在 `temp/player-tests.log`、`temp/player-large-failure.log`，修复后完整重跑通过。

自动化验证涵盖媒体处理和实际按钮导出；跨窗口鼠标拖放、所有系统视频解码器、带音频播放、所有 DPI / 多显示器布局未做完整兼容性矩阵。拖入文件入口已实现，但不将代码检查等同于跨窗口实拖验收。悬停延迟配置为 150 毫秒，未进行逐毫秒可见延迟测量。摄像头、各硬件编码器和第三方上传授权不在本次完整验证范围。

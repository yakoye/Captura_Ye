## 实现范围

采用最终确认的交互：单击预览并设置范围起点；双击／勾选框／Ctrl 单击增减选择；Shift 连续选择，Ctrl+Shift 追加。右上勾选框保留；橙框表示当前预览，蓝底和勾选表示导出集合。左右键与滚动不改变勾选及起点。取消选中位于删除选中左侧。

折叠和展开共享当前宽度，默认 960×780、展开最小 860×640；折叠高度 90，恢复保存的展开高度。选择目标成功及重新选择成功时折叠，取消或恢复配置不折叠；录制流程在编码器初始化前折叠。录制结果继续自动展开回看。

导出栏 196 DIP；卡片宽 117、画面高 57 DIP，为旧尺寸 75%。时间轴最小高度 144，避免卡片时间被滚动条裁切。预览深色边框按媒体宽高比适应可用空间，画面完整保留；竖屏媒体仍可能在整体工作区两侧留出空间。

## 导出问题定位

旧实现无论选 PNG、MP4 或 GIF，都会先把 PNG 写入最终输出目录，MP4/GIF 合成后仍保留图片。用户截图状态栏已有合成 MP4 成功提示，因此不能将全部现象归为下拉选择失效。本版将合成图片移至独立临时目录，结束后清理；MP4/GIF 最终目录仅包含 selected.mp4／selected.gif 和 frames.csv，并增加打开导出文件入口。格式改为显式 Tag 标识，不依赖下拉项位置；PNG 导出不再被无关的合成帧率输入阻止。

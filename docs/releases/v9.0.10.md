# Captura Ye 中文版 v9.0.10

- 修复裁剪 MP4 的前置丢弃包被误计入帧索引的问题；负时间戳、丢弃标记和重复时间戳会在后台回退到逐帧校验，预览仍可先使用。VP8/VP9 等可能一包多帧的编码采用后台逐帧索引。
- 长视频先显示预览和可播放进度，再在后台建立精确索引；完成前支持播放、按秒定位和拖动，帧号标记“约”，完成后开放精确选帧、编辑和导出。常见视频使用数据包时间戳建立索引，其他格式在后台回退到逐帧读取。
- 左右键沿用最近点击的 1 帧、1 秒或 5 秒按钮步长；六个前后步进按钮支持按住连续移动。拖动进度条持续定位和更新画面，后台只保留最新待解码目标。
- 在帧时间轴右侧增加“移除重复：相似度 X%　应用　取消”。比较原尺寸画面，100% 仅移除像素完全相同的连续帧，保留每组首帧；取消扫描不改时间轴。
- 支持删除选中帧、每 N 帧保留 1 帧、撤销和重做；只修改当前工作区，原文件保留。至少保留一帧，编辑后时长相应缩短。
- 编辑后的缩略图、播放、逐帧、秒定位和导出统一映射到原始帧；PNG 清单仍记录源帧号与源时间。视频编辑预览使用有界预取，不创建临时重编码视频，帧编辑预览和合成针对画面、不含音频。
- 当前查看帧在导航和播放时尽量固定在时间轴第二张，左侧保留前一帧，首尾按边界处理；暂停时可自由滚动查看其他缩略图。
- 局部快捷键：Delete 删除所选，Ctrl+Z / Ctrl+Y 撤销与重做；输入框保留自身快捷键。编辑或撤销后重新选择导出帧。

交互参考 ScreenToGif 的删除、移除重复和减少帧数入口，像素指标、时间轴和播放实现由本项目独立完成。说明与边界见 docs/VALIDATION-v9.0.10.md。

验证包含 69 项核心和回归测试、中文资源、真实截图与 AVI/MP4、中文隔离安装及卸载、完整载荷 SHA-256；另记录可见界面检查与未覆盖的人工长按边界。

双击 build.cmd 编译打包，双击 release.cmd 完成构建验证、GitHub 发布和本地/NAS 双归档。

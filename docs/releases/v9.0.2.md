# Captura Ye 中文版 v9.0.2

- 补齐窗口录制的两行悬停说明；检查所有录制来源和编码器说明，防止遗漏多行英文。
- 悬停提示等待时间缩短为 150 毫秒；在控件间快速移动时及时切换提示，并扩大录制来源图标的提示区域。
- 启动时在后台自动查找 FFmpeg，找到后配置其所在目录。优先保留已有有效配置，先逐项检查 PATH，未找到时再查程序目录、WinGet、Scoop、Chocolatey 和常见安装目录；“配置 → FFmpeg”提供重新检测按钮。
- 删除检查 FFmpeg 时反复启动外部进程的逻辑，减少界面线程中的耗时操作。
- 预览区新增播放器，录制结束自动载入结果；支持拖入视频和 GIF、播放/暂停、拖动进度。
- 播放模式左右键按秒快退/快进、空格播放/暂停；选帧模式左右键逐帧、空格选中/取消。支持多选列表、连续范围选择和按原时间排序。
- 仅将选中帧导出为原尺寸 PNG、MP4 或循环 GIF；支持设置合成帧率，附带原始帧号和时间表，可直接打开导出目录。合成视频和 GIF 不含音频。
- 优先通过 ffprobe 读取真实帧时间；未附带 ffprobe 时使用 FFmpeg 后台扫描。快速连按合并过时请求，限制图像缓存内存，支持取消处理。
- 保留实时录制预览和“仅预览”模式；增加明确切换入口。
- 录制完成后，在主窗口保留完整保存路径，并提供“打开文件”“打开所在文件夹”。通知也显示完整路径，附带打开入口。
- 修复启动外部程序时丢失参数的问题，确保“打开所在文件夹”能够定位选中的录制文件。

安装程序支持简体中文和英文选择。双击 `build.cmd` 编译打包；双击 `release.cmd` 自动更新版本、验证、发布并归档到本地和 NAS。

自动检查包括中文资源、38 项核心与回归测试、实际截图及 AVI/MP4 录制、中文静默安装/卸载和文件哈希校验。MP4 测试使用本机 FFmpeg；未找到系统 FFmpeg 时会明确报告跳过该项。

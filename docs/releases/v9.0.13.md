# Captura Ye 中文版 v9.0.13

- 单击帧预览并设置连续选择起点，橙框表示当前查看；双击、勾选框或 Ctrl 单击增减选择，其他已选帧保留。Shift 单击连选，Ctrl+Shift 追加范围；滚动与左右键预览不改变起点或勾选。
- 时间轴增加“取消选中”，位于“删除选中”左侧；保留右上勾选框、蓝底选中与橙框查看的独立状态。
- 修正 MP4/GIF 输出目录混有合成中间 PNG 的问题：只输出所选格式及帧清单，完成后可直接打开导出文件；格式通过稳定标识传递，新增真实下拉框到 FFmpeg 导出的端到端检查。
- 折叠与展开保持宽度，只收起高度；默认展开 960×780，最小 860×640。成功选择录制目标或开始录制自动折叠，取消目标选择不折叠；保存后展开回看。
- 导出面板从 248 收窄至 196 DIP；帧卡片宽度及画面高度缩至原来的 75%，保留可读时间文字。预览边框按媒体比例适应，继续支持放大、缩小、拖动与适应。
- 自动化覆盖连续／离散选择、双击防重复切换、取消选中、窗口宽度保持、录制前折叠、横竖视频布局及 PNG／MP4／GIF 的实际输出。

继续使用 build.cmd 编译验证、release.cmd 发布及本地/NAS 双归档，版本自动递增。详细结果与覆盖边界见 docs/VALIDATION-v9.0.13.md。

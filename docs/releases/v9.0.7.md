# Captura Ye 中文版 v9.0.7

- 帧号与当前时间 / 总时间放在“最后一帧”按钮右侧，与播放按钮同一行；去掉“当前查看”前缀。前后逐帧按钮显示图标与“1帧”，悬停仍为上一帧、下一帧，最右端保留简写的“逐帧”开关。
- 删除重复标题，文件名与打开文件、实时画面、帮助入口集中到右侧面板上方，扩大左侧预览。
- 蓝色主按钮统一为“导出”，使用上方所选图片、MP4 或 GIF 格式。
- 重新设计回看工作区：左侧大预览、底部缩略图时间轴、右侧独立导出设置；主操作固定可见，帧率框支持小数并增加宽度。
- 播放栏采用现成 Material Design Icons 图标，依次为第一帧、前5秒、前1秒、上一帧、播放/暂停、下一帧、后1秒、后5秒、最后一帧，提供中文提示。缩略图左上显示数字、右上勾选、下方保留时间，去除“第 X 帧”标签。
- 压缩帧卡片下方留白；快捷键和多选说明移到右上角问号，底部只在处理、完成或出错时显示实际状态。
- 当前查看帧与导出选择分离；支持复选框任意离散多选、Ctrl 增减、Shift 范围、Ctrl+Shift 追加范围、全选和清空。播放与逐帧查看保留原有多选。
- 选帧快捷键改为 Ctrl+Enter；空格统一播放/暂停。仅在预览和时间轴生效，不抢占文字、数字和下拉框的键盘输入。
- 缩略图按可见区域及邻近范围后台加载，使用虚拟化列表和有上限的缓存；滚轮横向滚动，Home/End 首尾定位。
- 导出图片、MP4、GIF 统一使用选中帧的快照，按原时间排序；保留帧号与时间清单。视频和 GIF 合成不含音频。
- 回看时自动折叠录制参数；展开工作区可调整大小，保留紧凑录制窗口。新增 --review 文件路径启动入口。

交互参考 ScreenToGif 的帧列表与预览布局，使用本项目的媒体和选择模型实现。参考说明见仓库中的 docs/FRAME-EDITOR-DESIGN.md。

验证包括中文资源检查、48 项核心与回归测试、截图和 AVI/MP4 录制、中文隔离安装/卸载及载荷哈希、可见缩略图多选和实际导出。具体证据与未覆盖项见 docs/VALIDATION-v9.0.7.md。

双击 build.cmd 编译打包；双击 release.cmd 完成构建、验证、GitHub 发布和本地/NAS 双归档。

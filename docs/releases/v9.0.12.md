# Captura Ye 中文版 v9.0.12

- 查看与勾选导出分开：单击缩略图只预览，勾选框只增减导出帧。普通左右键、播放和拖动定位均保留已有勾选，多选后不会跳回第一张。可依次查看、确认并勾选第 1、3、7 帧。
- 预览右下角增加缩小、倍率、放大和“适应”，支持在预览区域 Ctrl＋鼠标滚轮缩放，倍率为适应窗口的 0.25—8 倍。放大后可按住左键拖动画面或使用滚动条，适应时恢复倍率和位置。
- 缩放同时支持静态帧、视频播放、GIF 与编辑预览，切换帧保留倍率，打开新文件恢复适应；不修改源文件、勾选集合或导出分辨率。
- 主窗口增加最大化／还原按钮，也可双击顶部计时区域切换，拖动窗口边缘调整大小。图标继续来自固定版本 Material Design Icons，未手工绘制。
- 保留 Ctrl/Shift 显式多选、范围、批量导出、渐进导入、去重与撤销；同步更新关于、帮助及中文说明。

验证包含 85 项核心与回归，其中新增 6 项真实 WPF 控件离屏测试，覆盖实际按钮、卡片勾选、方向键、进度条事件和缩放布局；发布脚本自动保存 TRX 和离屏 PNG。另验证中文资源、真实截图及 AVI/MP4、中文隔离安装及卸载、完整载荷 SHA-256。可见界面与输入组合边界见 docs/VALIDATION-v9.0.12.md。

双击 build.cmd 编译打包；release.cmd 构建验证、发布 GitHub 并归档本地与 NAS，自动递增版本号。

## 原始失败与修复

v9.0.2 的自动媒体处理检查通过，但随后可见 GIF 回放失败，因此中止发布并保持草稿，保留原包、标签和日志，没有公开该版。v9.0.3 替换 GIF 连续播放后重新执行完整构建、38 项测试、录制、安装和可见 GIF 回放检查。

其他已修复问题和原始失败日志见 `docs/VALIDATION-v9.0.2.md`：新版 FFmpeg 参数移除、过长选帧表达式解析失败。产品已按版本选择参数、每批最多 64 个选帧条件，并合并连续范围。

## 发布和归档流程

`release.cmd` 调用统一发布脚本。脚本在发布前检查源码文件列表及 SHA-256，避免复用与当前源码不一致的包；提交项目、推送到 `yakoye/Captura_Ye`、创建草稿发行版、上传并回下载校验，校验后公开发行版。归档脚本再将文件复制到两个版本目录，并比较大小和 SHA-256。同名内容冲突时停止，NAS 失败时单独报告。

发布地址、最终资产哈希和双归档结果以实际脚本输出和 `dist/v9.0.1/SHA256SUMS.txt` 为准。

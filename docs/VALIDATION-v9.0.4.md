## 验证边界

原生自动化接口不能组合按住鼠标修饰键，因此 Ctrl/Shift 鼠标单击及 Shift 点复选框由选择模型测试和事件接线检查验证，未宣称完成真实按键加鼠标验收。未穷尽所有 DPI、屏幕尺寸、系统主题、视频编解码器及人工安装语言选择流程；中文安装路径通过静默安装实测。窗口自动化遇到用户操作保护或其他窗口覆盖时停止当前输入并刷新，未将被拦截输入计作产品通过。

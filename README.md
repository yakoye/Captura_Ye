# Captura Ye 中文版

基于 [Mathew Sachin / Captura](https://github.com/MathewSachin/Captura) 的 Windows 截图、屏幕与音频录制工具。保留上游功能，默认使用简体中文，补齐界面、悬停说明、录制模式、通知和错误提示。

项目地址：[yakoye/Captura_Ye](https://github.com/yakoye/Captura_Ye)。安装包与便携包见[发行版](https://github.com/yakoye/Captura_Ye/releases)。

## 使用

支持 Windows 10/11，需 .NET Framework 4.7.2 或更高版本。安装程序会检查框架版本；安装时可选择简体中文或英文。应用首次启动默认使用简体中文，可在“配置 → 界面”切换语言。

FFmpeg 会在后台自动查找：优先保留有效配置，否则先检查 PATH，未找到时再查程序目录和常见安装位置。“配置 → FFmpeg”可重新检测。

预览在开始录制后显示；若只预览不保存，在“配置 → 视频 → 视频编码器”选择“仅预览”，再点击红色录制按钮。录制完成后，主窗口显示完整文件路径，可点“打开文件”或“打开所在文件夹”，也可从“配置 → 最近记录”再次打开。

### 回看、缩略图多选和导出

展开主窗口，进入“回看与选帧”。录制完成后自动展开并载入结果；也可点“打开媒体”或将视频/GIF 拖入预览区。左侧预览，底部是帧时间轴，右侧是导出设置。默认窗口为 960×780，展开最小为 860×640（以系统可用区域为上限）；折叠保持宽度，只收起高度。成功选择录制目标或开始录制时自动折叠，取消目标选择不折叠。窗口支持拖动边缘、最大化／还原以及双击顶部计时区域切换。预览边框适应画面比例，导出面板宽 196 DIP，帧卡片宽 117 DIP、画面高 57 DIP，均为原来的 75%；时间轴高度仍可拖动调整。

**当前查看位置与导出选择互相独立。** 橙框和“查看中”表示预览位置，蓝底和勾选表示将要导出的帧；左右键、播放、进度条和滚动不会清除已选帧，也不移动范围起点。

| 操作 | 行为 |
| --- | --- |
| 勾选每张缩略图的复选框 | 增减任意离散帧，保留其他选择及当前预览位置 |
| 单击缩略图画面 | 预览该帧并设为范围起点，保持全部勾选不变 |
| 双击缩略图画面 | 预览并增减这一帧的勾选，保留其他选择 |
| Ctrl + 单击缩略图 | 增减该帧，保留其他选择 |
| Shift + 单击缩略图 | 从单击或选择操作设置的起点连续选择，包含两端；继续 Shift 点击保留原起点 |
| Ctrl + Shift + 单击缩略图 | 将范围加入现有离散选择 |
| Ctrl + Enter | 增减当前查看帧 |
| Ctrl + A / Ctrl + Shift + A | 全选 / 清空选择 |
| 时间轴“取消选中” | 清除全部勾选，保留预览位置；位于“删除选中”左侧 |

例如单击第 5 帧后滚动至第 15 帧，再 Shift 单击第 15 帧，选择 5～15；继续 Shift 单击第 20 帧则选择 5～20。Ctrl 单击可选择第 5、15 等离散帧；Ctrl+Shift 追加连续范围。

缩略图按可见范围和邻近少量帧加载，缓存有数量上限。滚轮可横向滚动；Home / End 查看首帧、末帧，保留已有选择。高级“范围选择”仍可指定起点再添加到当前帧。

| 模式 | 左右方向键 | 空格 |
| --- | --- | --- |
| 播放模式 | 按 1 秒快退 / 快进；Shift 加速为 5 秒 | 播放 / 暂停 |
| 逐帧模式 | 上一帧 / 下一帧 | 播放 / 暂停 |

“上一帧 / 下一帧”按钮和缩略图点击会进入逐帧模式。**空格播放，Ctrl + Enter 增减当前帧。** 快捷键仅在预览或时间轴内生效；输入框、数字框、下拉框和按钮保留各自键盘行为。左右键仅预览，连续选帧使用 Shift＋单击。

在右侧选择导出格式，再点击蓝色“导出”按钮：

- **图片**：仅导出选中帧，每帧一张原尺寸 PNG；附带 `frames.csv`，记录图片、源帧号和时间，方便提供给 AI 分析。
- **视频**：仅将选中帧按原时间顺序合成为 MP4，不包含未选中的间隙帧。
- **GIF**：仅将选中帧按原时间顺序合成为循环 GIF。

视频和 GIF 按界面设置的 1—60 帧/秒合成，均不含音频。帧率允许小数，输入框有足够宽度；例如选中 30 帧、设为 10 帧/秒，结果长约 3 秒。MP4 遇到奇数尺寸会补齐到偶数尺寸，PNG 保留原尺寸。需要保留连续片段的原音频时，使用“配置 → 关于 → 工具”中的原有裁剪工具。

首次导出默认使用源文件旁的 `Captura-exports`，也可更改目录；之后记住该位置。每次创建独立子目录，保留之前的输出。MP4/GIF 目录中仅包含 `selected.mp4` 或 `selected.gif` 以及 `frames.csv`，合成中间图片在独立临时目录中清理。完成后可“打开导出文件”或“打开导出目录”；失败和取消明确提示，并保留输出目录中的部分结果。

预览和抽帧使用自动发现的 FFmpeg。优先通过同目录或 PATH 中的 ffprobe 建立真实帧索引；没有 ffprobe 时会后台顺序扫描，较长文件需要等待，可取消。GIF 使用 Windows 原生图像解码播放，逐帧和导出仍读取原 GIF。系统缺少某视频编码的播放组件时，会提示不能连续播放，仍可逐帧查看和导出。

程序关闭时，可通过 `captura.exe --review "视频或GIF的完整路径"` 启动并直接载入文件，适合脚本调用。

- 安装版：运行 `CapturaYe-v版本号-Setup.exe`。
- 便携版：将 `CapturaYe-v版本号-Portable.zip` **完整解压**，运行 `CapturaYe/captura.exe`。请保留同目录中的 `lib`、`Languages`、`Settings` 和配置文件。
- 录制 MP4 等格式需要 FFmpeg。程序会从已配置目录、程序目录或系统 PATH 查找，也可在“配置 → FFmpeg”指定目录。
- 截图、AVI 录制不需要额外下载 FFmpeg。摄像头和音频录制需要可用设备。
- Imgur、YouTube 等网络上传功能需要自行配置服务凭据；本项目不内置私有凭据。

## 双击编译与发布

入口文件名均为英文，脚本提示和说明使用中文。

| 入口 | 操作 |
| --- | --- |
| `build.cmd` | 编译 Release、检查中文资源、运行核心与 WPF 离屏测试和实际截图/录制检查、生成便携 ZIP 和中文安装 EXE、静默安装/卸载与哈希验证 |
| `release.cmd` | 自动选择未发布版本，执行上述全部步骤，提交当前项目修改，推送源码和版本标签，创建 GitHub Release，回下载校验，再复制到本地及 NAS |

第一次构建需安装 Git、支持 .NET Framework 构建的 .NET SDK（本次使用 .NET SDK 10.0.401）。发布还需 GitHub CLI，并使用 `gh auth login` 登录有仓库写权限的账号。NuGet 会自动还原依赖；首次打包会下载固定版本 Inno Setup 6.7.3，验证 SHA-256 和发布者签名后，准备到 `temp/build-tools/Inno`。本仓库包含匹配的简体中文安装语言文件。

双击 `release.cmd` 即表示发布**当前工作区中的项目修改**。脚本会通过 `git add --all` 提交未提交文件；发布前应将凭据和私人文件移出项目。构建中间文件、日志和发布输出已排除在 Git 之外。脚本保留原有 `origin`，另用 `publish` 远程指向本仓库，不使用强制推送。

输出位置：`dist/v版本号/`。日志：`temp/logs/日期时间/`。源码版本来自 `src/Captura/Properties/AssemblyInfo.cs`；已存在同版本发行版时，`release.cmd` 自动增加补丁版本。关于页面的发行日期会在构建时更新。

高级用法（自动化也调用同一脚本）：

```powershell
# 指定版本编译、测试和打包
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/release.ps1 -Version 9.0.13

# 发布已经验证的现有包，不重新编译
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/release.ps1 -Publish -Archive -ReusePackage

# 仅对已有发布包执行双归档
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/archive-release.ps1 -Source dist/v9.0.1 -Version 9.0.1
```

归档目录固定为：

- `C:\Users\color\Downloads\yakoye-release\Captura_Ye\v版本号\`
- `\\192.168.7.100\Downloads\yakoye-release\Captura_Ye\v版本号\`

归档安装 EXE、便携 ZIP、发布说明、构建记录和 SHA-256 清单。便携 ZIP 已包含完整运行依赖，不再将一百多个小文件逐个传输到 NAS；解压后的便携目录仍保留在本机 `dist/v版本号/CapturaYe/`。需要额外复制完整便携目录时，可单独调用归档脚本的 `-IncludePortableFolder` 参数。保留旧版本；同名文件内容不一致时停止，绝不覆盖。NAS 不可达时会报告未完成，并保留已成功校验的本地归档。GitHub 发布和归档分别验证，任一失败都会返回非零退出代码。

## 验证边界

脚本自动验证中文资源和引用、默认语言、安装语言配置、核心录制与图像对象逻辑、实际截图及 AVI 录制（有系统 FFmpeg 时也检查 MP4）、EXE 版本、运行依赖，以及隔离测试目录内的中文静默安装、载荷哈希和卸载。安装测试使用独立应用标识并禁用快捷方式，不替换用户已经安装的版本。

WPF 离屏测试实例化真实回看控件和主题，在独立 STA 线程布局，派发按钮、卡片、勾选、方向键与进度条事件，验证状态隔离、步长切换、缩放边界、窗口尺寸变化和适应后滚动条收起。测试不显示窗口、不注入系统输入；TRX 与离屏 PNG 存在本次 `temp/logs/时间戳/` 中，不因等待桌面视觉测试而跳过。

当前版本另外检查主窗口、设置、关于、颜色选择器、安装语言选择和录制来源提示。设备驱动、各显卡硬件编码、云端上传授权及所有第三方服务不属于完整兼容性保证；FFmpeg 的原始编码参数、设备名称和异常堆栈保留技术信息。

## 播放器图标与帧角标

播放栏从左到右：第一帧、前5秒、前1秒、上一帧、播放/暂停、下一帧、后1秒、后5秒、最后一帧。按秒移动与逐帧按钮始终执行各自步长；逐帧模式复选框只决定左右键的行为。播放/暂停共用一个位置，随状态切换图标，悬停显示中文提示。

图标来自 [Material Design Icons](https://github.com/Templarian/MaterialDesign-SVG)，没有手工绘制；来源和许可随分发包提供。缩略图左上仅显示帧号数字，右上为独立勾选框，下方为时间。橙色“查看中”位于图片底部，查看与导出选择保持独立。

点击回看工作区右上角的问号查看多选和快捷键说明；底部不再常驻显示操作说明，仅在处理、完成或出错时显示实际状态。帧卡片贴合内容，缩短下方留白。

播放按钮行在“最后一帧”右侧显示帧号与当前时间 / 总时间；前后逐帧按钮同时显示图标和“1帧”文字，悬停提示仍为“上一帧”“下一帧”，最右端是“逐帧”开关。

文件名与打开文件、实时画面、帮助入口集中在右侧导出面板上方，将左侧空间完整交给预览。

右侧工具栏与文件名位于灰色导出卡片外；卡片中的已选帧数使用正文大小加粗。发布脚本兼容 Windows PowerShell 5.1 已有草稿识别，缺失资产补传；下载失败会保留证据并自动使用 HTTP/1.1 重试，避免重复创建草稿。

## 帧编辑、去重与撤销

### 长视频导入与连续定位

打开视频后先读取基本信息并显示预览，精确帧索引在后台建立；此时可播放、按秒定位和拖动，临时帧号显示“约”。索引完成后自动开放选帧、去重、编辑和导出，无需重新打开。GIF 使用原有精确帧延时路径。索引失败时仍可播放和定位，重新打开文件可重试。

裁剪 MP4 的前置丢弃包、负时间戳、缺失或重复时间戳，以及可能一包多帧的编码，会在后台使用逐帧索引校验，避免把数据包号误当作实际显示帧号。

左右键沿用最近点击的“1帧 / 1秒 / 5秒”按钮步长；“逐帧”开关也可手动切换，关闭后恢复最近使用的秒步长。前后六个步进按钮按下立即移动，按住约 350 毫秒后每 110 毫秒重复移动，松开或移出按钮停止。拖动进度条会持续更新定位，系统播放器先提供即时画面，后台合并待处理目标并补上精确帧；不会堆积所有拖动请求。

在帧时间轴标题右侧设置相似度，点击“应用”扫描整个当前时间轴；100% 要求原尺寸 BGRA 像素完全相同，低于 100% 按像素差判断相似，保留每组首帧。扫描期间“取消”会终止任务，不修改当前时间轴。

- “删除选中”或 Delete：删除已勾选帧，至少保留一帧。
- “减少帧数”：每 N 帧保留第一帧，作用于整个当前时间轴。
- “撤销 / 重做”或预览、时间轴内 Ctrl+Z / Ctrl+Y：恢复帧编辑；输入框仍使用原有文本撤销。
- 编辑只改当前工作区，源文件保留。删除的帧不再参与播放和导出，时长相应缩短。编辑与撤销后重新选帧；导出清单中的帧号、时间指向原文件。
- 编辑后的视频预览及合成针对画面，不含音频；合成帧率由右侧设置决定。

鼠标单击哪一帧就只预览哪一帧，不增减勾选；勾选框只改变导出集合，不跳转预览。可先勾选第 1 帧，再点击第 3 帧确认后勾选，再查看并勾选第 7 帧，最终勾选 1、3、7，预览仍停在 7。普通左右键、播放和拖动定位不改勾选；Ctrl/Shift 显式多选及范围入口仍可使用。当前帧在可见范围内不移动时间轴，走到对应边缘后才滚动跟随。

预览区右下角提供缩小、倍率、放大和“适应”。也可在预览区使用 Ctrl＋鼠标滚轮，以指针所在位置为锚点缩放；倍率为相对于适应窗口的 0.25—8 倍。放大后按住左键拖动或拖动滚动条查看局部；“适应”恢复 1 倍并重置位置。切换帧或播放保留倍率，打开新文件恢复适应；缩放只影响查看，不改变原文件、导出分辨率或勾选集合。
